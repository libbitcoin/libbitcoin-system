# libbitcoin-system

Bitcoin primitives: blocks, transactions, scripts and their execution, hashes and cryptography, keys, addresses and wallets, encodings and serialization.

Documentation is at [libbitcoin.org/lib/system](https://libbitcoin.org/lib/system.html).

Download [Bitcoin Server (`bs`)](https://libbitcoin.org/download/index.html).

| | |
| - | - |
| Depends on | none |
| Header | `<bitcoin/system.hpp>` |
| Namespace | `libbitcoin::system` |
| Package | `libbitcoin-system` (pkg-config) |

Libbitcoin is a set of cross-platform C++20 libraries for building Bitcoin applications. See [all libraries](https://libbitcoin.org/lib/index.html) and [building from source](https://libbitcoin.org/building/index.html).
